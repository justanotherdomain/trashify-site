# trashify-site

Public pages for the Trashify app, served by GitHub Pages at https://justanotherdomain.github.io/trashify-site/

- `privacy.html`: privacy policy, linked from the app and both store listings
- `terms.html`: terms of use, including the subscription terms Apple requires
- `support.html`: support page and FAQ (the App Store's Support URL)

If the app starts sending different data (a new SDK, say), update `privacy.html` and the store-form answers in the app repo's `Play Store and App Store Screenshots/README.md` together.
